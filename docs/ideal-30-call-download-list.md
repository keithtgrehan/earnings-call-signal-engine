# Ideal 30-Call Download List

All targets require manual source confirmation before any transcript is downloaded, parsed, labelled, or promoted. Use company investor relations and SEC EDGAR first where possible; transcript vendors, exchange sites, Kaggle-style datasets, or MAEC-style corpora are references only when rights and provenance are clear.
