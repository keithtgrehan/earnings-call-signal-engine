# Problem Definition & Value Proposition

This planning note describes intended reviewer value and workflow fit. It should not be read as a validated claim about trading performance, market edge, or proven review-speed gains.

## Target User
The primary user is a self-directed retail trader or active private investor who follows earnings season closely and wants a more structured way to review each call. This user is serious about fundamental signals but does not have the time, team support, or institutional tooling to deeply process every long transcript.

## Core Problem
The user’s challenge is not lack of information; it is overload. Earnings calls are long, noisy, and unstructured, which makes it hard to quickly isolate the few moments that matter, especially subtle guidance shifts, changes in management confidence, and tone-change signals.

## Context and Impact
When this problem is not solved, review is slow and inconsistent, and important signal-bearing moments can be missed or interpreted differently from one call to the next. Retail traders may rely on broad summaries without clear transcript evidence, making it harder to understand what actually changed and where to inspect it in the source text.

## Value Proposition
The Earnings Call Signal Extraction Engine converts an earnings call into a structured, auditable signal summary focused on guidance shifts, tone-change moments, and transcript evidence. It is intended to help reviewers inspect what changed and where to look first in the source text.

## Intended User Outcomes
- More structured post-call review with clearer prioritization of high-signal moments.
- More consistent evidence presentation across different calls and reporting periods.
- Evidence-backed conclusions tied directly to transcript snippets.
- Clearer prioritization of what to review first without replacing user judgment.

## Scope Reminder
This product is a focused decision-support tool for retail trader earnings-call review. It is transcript-first and designed to structure interpretation, not automate trades. It does not attempt to replicate a full institutional research platform or act as an autonomous trading engine.
