# Benchmark Matrix Plan

## Implemented Now

- Deterministic extraction/scaffold.
- Manifest validation.
- Gold-label validation.
- Weak-label deterministic baseline.
- Optional local sklearn training scaffold if sklearn is already available.

## Not Implemented

- Real 30-call corpus.
- 100-150 call benchmark.
- Trained production model.
- Validated embeddings.
- Reranker benchmark.
- Long-context benchmark.
- Market-reaction correlation.

## Guardrail

Registries, weak labels, handcrafted fixtures, and sklearn smoke tests are not real validated training data and are not real validated ML. They are scaffolds for future review and benchmark work.
