# License And Usage Notes

- Do not commit raw large datasets, model weights, gated resources, or license-restricted corpora.
- Treat Hugging Face and Kaggle entries as references until exact dataset cards and terms are reviewed.
- SEC metadata is public but should be fetched with fair-access headers and refreshed as metadata, not as product proof.
- Non-commercial datasets are not suitable for unrestricted portfolio/product use without legal review.
- Audio/video affect datasets carry extra privacy and ethics risk; avoid emotion claims without human-reviewed evaluation.

## High-Priority Manual Reviews

- Loughran-McDonald Master Dictionary: Site terms/manual review required before redistributing dictionary files.
- Financial PhraseBank: Dataset card/license review required; do not redistribute without checking source terms.
- Public earnings-call transcript dataset candidates: Kaggle and vendor dataset licenses vary; often gated/manual.
- Qasper: Dataset license requires review; public research dataset.
- BEIR: Benchmark wrapper; component dataset licenses vary.
- QMSum: Dataset license/manual review required.
- openSMILE: License/manual review required for some use cases.
