# Loughran-McDonald Signal Mapping

This repo uses Loughran-McDonald as optional lexical support, not as a separate label set.

## Conservative Mapping

- LM `Negative` -> likely support for `risk_friction`
- LM `Uncertainty` + `Modal` -> likely support for `uncertainty_hedging`
- LM `Positive` -> possible support for `opportunity_commitment`, but weak on its own
- LM `Constraining` -> possible support for `risk_friction`
- LM `Litigious` -> possible support for `risk_friction`

## What Neutral Means Here

- `neutral` is not an LM category
- use `neutral` only when there is no strong friction, commitment, or hedge cue and the text is mostly logistics, acknowledgement, or status

## Boundary Notes

- LM terms are evidence aids, not labels by themselves
- a single LM match should not override clearer transcript context
- local human review remains required before any candidate is promoted
- the transcript-first deterministic system remains canonical
