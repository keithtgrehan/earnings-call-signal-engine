# Canonical Project Sources

ChatGPT Project Sources should be the compact, current memory used by Signal
Engine 2.0 specialist chats and the Control Room. Sources are not a dumping
ground. They should be small, current, canonical, and easy to reconcile with the
GitHub repository.

## Recommended Sources

- README.
- Product scope.
- Roadmap.
- Evaluation plan.
- Execution roadmap.
- Gold label schema.
- Argilla workflow docs.
- Corpus manifest docs.
- Benchmark reports.
- `AGENTS.md`.
- Agent operating docs.

## Selection Rules

- Prefer one canonical source per topic.
- Prefer current status docs over historical planning memos.
- Prefer concise operating docs over long chat transcripts.
- Prefer GitHub-backed files over pasted notes.
- Keep sources aligned with the default branch or the active task branch.

## Maintenance Rules

- Remove stale docs when they are superseded by a newer canonical source.
- Do not add duplicate memos that conflict with existing source files.
- Mark planned, proposed, and speculative work clearly.
- Refresh sources after major branch merges, evaluation updates, or label schema
  changes.
