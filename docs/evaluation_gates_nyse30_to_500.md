# Evaluation Gates: NYSE 30 To 500

## 30-Call Pilot

Pipeline readiness only. This proves the local deterministic and review workflow can run when registered transcript paths exist.

## 100 Valid Gold Labels

Signal extraction evaluation readiness begins only after at least 100 valid adjudicated labels pass validation.

## 100-150 Calls

Retrieval benchmark readiness requires enough registered calls and evidence objects to measure recall@k, MRR, evidence-ID hit rate, citation validity, blocked-source count, latency, and reviewer usefulness.

## 500-Call Universe

The 500-call layer is metadata/readiness mapping only until source rights and registered transcripts exist.
