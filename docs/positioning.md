# Positioning

## Core narrative

This project is a deterministic conversation signal engine for noisy, real-world exchanges.

Primary use case:

- customer support QA
- service-risk detection
- escalation pattern review

Secondary use case:

- earnings-call Q&A analysis as a reference domain that proves the engine can handle long, messy, domain-specific conversations

## Product claim

The engine does not predict intent with opaque models. It extracts explainable signals that can be traced back to message text and simple deterministic rules.

## Why this positioning is credible

- one row per conversation keeps downstream review simple
- deterministic features are testable and reproducible
- no external APIs keeps runs local and auditable
- earnings-call assets remain in-repo as proof that the system generalizes beyond support tickets
